# Proposal: fix-page-reorder

## Why

Ручное переупорядочивание страниц (SortableJS) фактически не работает: перетаскивание либо мертво, либо перемешивает не те карточки, и на десктопе, и на телефоне. Порядок страниц — ключ к финальному PDF, без рабочего reorder MVP неполноценен.

## What Changes

Диагноз по текущему коду (`web/app.js:163-178`, `web/index.html:87-88`) — три дефекта:

- **Sortable не переинициализируется.** `#imageGrid` живёт внутри `<template x-if="view==='grid'">`; переход grid → result → «Создать ещё раз» уничтожает и пересоздаёт DOM-узел, а `initSortable()` вызывается только из `addFiles`. Новая сетка остаётся без Sortable — drag мёртв.
- **Сдвиг индексов на единицу.** Первый ребёнок `#imageGrid` — сам элемент `<template x-for>`; без опции `draggable` Sortable учитывает его при расчёте `oldIndex`/`newIndex`, и `splice` двигает не те элементы массива.
- **Конфликт DOM-мутаций Sortable и Alpine `x-for`.** Sortable сам переставляет узел в DOM; последующий keyed-патч Alpine поверх мутированного DOM даёт дубли/пропажи карточек. Требуется откат DOM-перестановки перед изменением массива.

Исправления: переинициализация Sortable при каждом монтировании сетки, `draggable: '.thumb-card'`, откат DOM-мутации в `onEnd` перед `splice`. Плюс e2e-проверка drag на десктопе и smoke touch-настроек для мобильных.

### New Capabilities

(нет)

### Modified Capabilities

- `canvas-pipeline`: добавляется требование надёжности переупорядочивания — drag-reorder работает после любых переключений экранов, индексы соответствуют карточкам, порядок в сетке всегда равен порядку страниц в PDF. (Капабилити из активного change `add-canvas-pipeline`, главный спек ещё не синхронизирован — delta содержит ADDED-требование.)

## Impact

- `web/app.js` — `initSortable()` и вызовы (переинициализация при показе grid, опции Sortable, логика `onEnd`).
- `web/index.html` — возможно `x-init`/`x-effect` хук на контейнере сетки.
- Тесты: Playwright e2e drag-сценарий (reorder → генерация → порядок страниц в PDF).
- Зависимости не меняются (SortableJS 1.15.2 остаётся).
