# canvas-pipeline — delta (add-brand-home-reset)

## ADDED Requirements

### Requirement: Возврат на главную по логотипу
Клик (и активация с клавиатуры) по логотипу в шапке SHALL возвращать приложение на пустой главный экран из любого состояния, сбрасывая контекст сессии: очередь изображений с освобождением их objectURL, готовый PDF, баннеры ошибок и лимита, состояние прогресса генерации. Если в момент активации идёт генерация, воркер SHALL быть остановлен, его результат отброшен. Настройки PDF SHALL сохраняться.

#### Scenario: Сброс из сетки
- **WHEN** в сетке есть карточки и пользователь кликает по логотипу
- **THEN** приложение показывает пустой главный экран, очередь пуста, objectURL миниатюр освобождены, настройки PDF прежние

#### Scenario: Сброс во время генерации
- **WHEN** идёт генерация PDF и пользователь кликает по логотипу
- **THEN** воркер остановлен, приложение на пустом главном экране, баннер ошибки не появляется

#### Scenario: Сброс с экрана результата
- **WHEN** готовый PDF показан на экране результата и пользователь кликает по логотипу
- **THEN** приложение на пустом главном экране, objectURL PDF освобождён, повторная генерация начинается с чистого прогресса
