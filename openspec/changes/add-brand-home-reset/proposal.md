# Proposal: add-brand-home-reset

## Why

Логотип `.brand` в шапке — привычная точка «вернуться в начало», но сейчас это статичный блок. Пользователю нужен быстрый способ начать заново с любого экрана (сетка, генерация, результат) одним кликом.

## What Changes

- Клик по `.brand` возвращает на пустой главный экран и сбрасывает контекст сессии: очередь изображений (с освобождением objectURL миниатюр), готовый PDF, баннеры ошибок/лимита, состояние генерации.
- Если в момент клика идёт генерация — воркер терминируется, результат отбрасывается.
- Логотип получает интерактивную семантику (курсор, доступность кнопки).
- Настройки PDF (формат, поля, качество, имя) сознательно НЕ сбрасываются — это предпочтения, а не контекст сессии.

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `canvas-pipeline`: добавляется требование «возврат на главную по логотипу» — сброс сессии из любого экрана, включая остановку активной генерации. (Капабилити из активного change `add-canvas-pipeline`; главный спек ещё не синхронизирован — delta содержит ADDED-требование.)

## Impact

- `web/app.js` — новый метод `goHome()` (terminate воркера + существующий `clearAll()` + сброс `job`).
- `web/index.html` — `.brand` становится кликабельным.
- `web/styles.css` — курсор/hover для `.brand`.
- Зависимостей и серверной части не касается.
