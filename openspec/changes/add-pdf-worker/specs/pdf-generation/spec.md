# pdf-generation — delta

## ADDED Requirements

### Requirement: Генерация в Web Worker
Сборка PDF SHALL выполняться в Web Worker (module): decode, поворот, размещение по математике `pipeline-math.js`, JPEG-энкод и `embedJpg` — вне главного потока. Страницы SHALL обрабатываться последовательно, не более одного полноразмерного изображения в памяти одновременно. Карточки в состоянии ошибки SHALL NOT попадать в генерацию.

#### Scenario: UI живой во время генерации
- **WHEN** генерируется PDF из 30 фото по 12 МП
- **THEN** анимация прогресса остаётся плавной, главный поток не блокируется циклом рендера

#### Scenario: Ошибки исключены
- **WHEN** в очереди 5 карточек, из них 2 в состоянии ошибки
- **THEN** PDF содержит 3 страницы

### Requirement: Применение настроек
Каждая страница SHALL рендериться по настройкам: формат/ориентация через `resolvePage`, поля и fit/fill через `placeImage`, JPEG-качество из слайдера, пользовательский поворот 0/90/180/270. DPI рендера SHALL быть 300 с капом 200 на мобильных (`effectiveDpi`, требование browser-compat). Имя файла SHALL проходить `sanitizeFilename` + суффикс `.pdf`.

#### Scenario: Поворот в PDF
- **WHEN** фото 4000×3000 повёрнуто пользователем на 90° и генерируется на A4-портрете
- **THEN** страница PDF содержит изображение в вертикальной ориентации (3000×4000), размещённое по fit/fill

#### Scenario: Кап DPI на телефоне
- **WHEN** генерация запущена на мобильном устройстве
- **THEN** растр страниц рендерится при 200 DPI

### Requirement: Реальный прогресс
Воркер SHALL отправлять `{done, total}` после каждой обработанной страницы; счётчик «n из m» на экране результата SHALL отражать эти сообщения, таймерная симуляция SHALL быть удалена.

#### Scenario: Счётчик соответствует работе
- **WHEN** обработано 7 страниц из 20
- **THEN** экран результата показывает «07 / 20»

### Requirement: Доставка готового PDF
По завершении SHALL выполняться автоскачивание через `<a download>` с blob URL; кнопка «Скачать PDF» SHALL использовать тот же URL. При `navigator.canShare({files})` для готового файла SHALL отображаться кнопка «Поделиться», открывающая share sheet; отказ пользователя от шаринга SHALL NOT считаться ошибкой. Blob URL предыдущей генерации SHALL отзываться при старте новой.

#### Scenario: Автоскачивание на десктопе
- **WHEN** генерация завершена в десктопном Chrome с именем файла «отчёт сканы»
- **THEN** скачивается валидный PDF с именем `scans.pdf`-подобным санитизированным именем (`sanitizeFilename`), кнопка «Скачать PDF» скачивает тот же файл повторно

#### Scenario: Share на iOS
- **WHEN** генерация завершена на iOS Safari 16.4+
- **THEN** доступна кнопка «Поделиться», открывающая системный share sheet с PDF-файлом

### Requirement: Ошибка генерации
Ошибка в воркере (файл не декодируется, сбой pdf-lib) SHALL прерывать генерацию целиком: пользователь видит сообщение об ошибке и возвращается к сетке; частичный PDF SHALL NOT выдаваться.

#### Scenario: Сбой посреди генерации
- **WHEN** пятый из десяти файлов не декодируется в воркере
- **THEN** генерация прервана, показано сообщение об ошибке, очередь и настройки не потеряны
